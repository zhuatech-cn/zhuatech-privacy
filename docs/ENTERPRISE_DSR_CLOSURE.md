## 业务闭环

请求受理 → 身份核验 → 权利分类 → 数据检索 → 留存与例外复核 → 受托方协同 → 响应复核 → 删除证明 → 送达与办结。

## 核心控制

- 强制门禁：身份、请求类型、适用地域、法定留存、响应材料、法定时限、职责分离和审计证据。
- 复核事项：完整数据源检索、法定例外、受托处理方通知和删除/匿名化证明。
- 决策结果：`COMPLETE`、`REVIEW`、`BLOCKED`，均附带可解释的阻断原因与行动清单。

## 接口

`POST /api/enterprise/privacy/data-subject-request-closure`

该接口适合接入隐私门户、工单系统或合规驾驶舱；身份平台、消息渠道和数据删除执行器仅预留适配器，由使用方自行配置。
